# Genesys Cloud Add-on for Splunk

|                          |                           |
|--------------------------|---------------------------|
| Version                  | 0.4.3                     |
| Vendor Products          | Genesys Cloud             |
| Splunk platform versions | 9.3.x, 9.4.x, 10.x        |
| CIM                      | 5.0.0                     |
| Platforms                | Platform independent      |


## Compatibility

This add-on provides data inputs and CIM-compliant knowledge objects for use with other Splunk applications, such as [Splunk Enterprise Security (ES)](https://www.splunk.com/en_us/products/enterprise-security.html) and [Splunk IT Service Intelligence (ITSI)](https://www.splunk.com/en_us/products/it-service-intelligence.html).

For detailed information about compatibility with other software, CIM versions, and platforms, see [Release notes](https://github.com/splunk/genesys_cloud_ta/releases) for the Genesys Cloud Add-on for Splunk.
